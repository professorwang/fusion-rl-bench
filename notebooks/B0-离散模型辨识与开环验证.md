# B0 报告：实际控制周期（0.5ms）离散模型辨识与开环验证（2026-09-27）

> 阶段 B 首个验收点：**离散模型的一步/多步预测与原模拟器一致性**。
> 结论：**通过（带限定条件）**——一步预测与主导不稳定特征值均与原模拟器一致；多步开环在不稳定通道上的指数发散属该不稳定模的固有行为（233/s），不构成对反馈设计的障碍。

## 一、方法（按复核建议执行）

不把上游内部雅可直接当作控制矩阵，而是做**数值系统辨识**（同时验证了"电压映射+积分步骤"链路）：

- 状态 x = [12 个主动线圈电流, Rx, Zx, Zcur, Rin]（16 维），输入 u = P6/D5/P5 电压（3 维），偏差坐标 dx = x − x_baseline
- 激励：100 个 rollout × 40 步随机电压 U(±30V)，共 4000 样本，最小二乘拟合 dx_{k+1} = A dx_k + B du_k
- 代码：`scripts/sysid_linear.py`；模型：`results/sysid_model.npz`；指标：`results/sysid_validation.json`

## 二、结果

### 一步预测（留出 rollout，50 步平均相对误差）

| 通道 | 平均相对误差 |
|---|---|
| 线圈电流（12 维均值） | 3.8% |
| Rx | 13.6% |
| Zx | 1.8% |
| **Zcur（控制目标）** | **1.3%** |
| Rin | 7.3% |

### 主导特征值对比（B0 关键验收指标）

| 量 | 值 |
|---|---|
| 模拟器诊断增长率 233.43/s 对应离散特征值 | 1.1238 |
| 辨识模型 A 的最大特征值（模） | **1.1254** |
| 偏差 | **0.0016（≈0.14%）** |

辨识模型还正确给出了次不稳定模（1.038、1.027…）。

### 多步开环（50 步方波电压程序，模拟器 vs 模型）

| 通道 | 归一化 RMSE | 说明 |
|---|---|---|
| Rx | 0.8% | 一致 |
| Zx | 3.8% | 一致 |
| **Zcur** | 72% | **预期内的指数发散**（非模型缺陷） |
| Rin | 1.8% | 一致 |

Zcur 的发散机制：开环不稳定模每步 ×1.12，50 步放大 ~320 倍——任何有限精度模型都无法在开环下约束不稳定通道，**这正是需要反馈控制的原因**。对 LQR 设计而言，重要的是不稳定特征值被准确捕获（0.14% 偏差）且系统可稳定，二者均满足。

图：`assets/sysid_openloop.png`（稳定通道贴合，Zcur 通道发散轨迹对照）。

## 三、验收判定

- [x] 一步预测与原模拟器一致（Zcur 1.3%、各通道 ≤14%）
- [x] 主导不稳定特征值与原模拟器一致（0.14%）
- [x] 多步开环稳定通道一致；不稳定通道发散机制已解释并记录
- [ ] **进入 B1 的前提已满足**：可在该模型上设计 LQR/LQG，再上模拟器做闭环对照（这才是对不稳定通道的正确验证方式）

## 四、备注（诚实边界）

- 模型仅在基线平衡邻域（±30V 激励范围）有效；大扰动下线性化失效；
- Rx 通道误差偏大（13.6%），LQR 若纳入 Rx 通道需关注；
- 辨识输入只用了 3 个控制线圈；全 12 通道模型留待需要时再扩。
